# Fidelity Checklist

- [ ] Approved visual hierarchy is preserved.
- [ ] Typography matches the source or approved design system.
- [ ] Icons and logos are exact source assets when strict fidelity applies.
- [ ] UI structure is not replaced with generic SaaS cards or invented product UI.
- [ ] Reconstruction preserves proportions, spacing, radii, colors and silhouettes.
- [ ] Template defaults have not contaminated the approved visual language.
- [ ] Re-composed checkpoints match the approved reference closely.
- [ ] No hidden flattened foreground is creating a false impression of layer separation.

## Pass Rule

All critical source-fidelity items must pass.
