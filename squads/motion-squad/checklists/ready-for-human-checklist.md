# READY_FOR_HUMAN Checklist

- [ ] Layer Readiness passed.
- [ ] Missing Assets Gate passed.
- [ ] Fidelity QA passed.
- [ ] Layer Separation Critic passed when component motion is required.
- [ ] Motion/Composition QA passed.
- [ ] Brand QA passed when applicable.
- [ ] Technical render/type validation passed.
- [ ] Preview is the intended delivery type, not an accidental animatic.
- [ ] No critical asset is missing.
- [ ] No scene is being passed off as component motion when it is actually a flattened slide.

## Pass Rule

Every mandatory item must pass before emitting `READY_FOR_HUMAN`.

Human approval is still required before final render/delivery.
