# Remotion Studio

Primeira superfície executável do Motion Agent.

O app consome os contratos do `@motion-agent/runtime` e oferece uma composição real para preview e render com Remotion.

## Preview

```bash
pnpm studio
```

## Listar composições

```bash
pnpm --filter @motion-agent/remotion-studio compositions
```

## Render de smoke test

```bash
pnpm render:demo
```

A composição inicial é `MotionAgentDemo`.
